# E-10 UI (uGUI + TextMeshPro)

**Goal:** diegetic interface in the spirit of the GDD's references: no permanent HUD, an arm terminal for inventory/status/logs, menus inside a terminal, accessible text.

**GDD sources:** `05 - Arte y Audio/04 - Interfaz Visual.md`, `06 - Experiencia/02 - UI y Menús.md`, `03 - Accesibilidad.md`, `04 - Guardado y Configuración.md`, `03 - Historia y Mundo/05 - Textos del Juego.md` (all strings), D-86, D-89, D-90, D-104.

## Deliverables
`Scripts/UI/TerminalView.cs` (tabs Inventory / Status / Logs; ECG + `HEALTH: FINE / INJURED / CRITICAL`; flashlight charge; subject code), `PromptView.cs` (`E` prompt), `ReticleView.cs`, `SubtitleView.cs` (≥ 32 px, background box, speaker colour + name, never colour alone), `SyncIndicator.cs` ("SYNCHRONIZING…"), `MenuView.cs` (title, main-menu terminal, 3 slots, Survival / Story), `OptionsView.cs` (rebinding, sensitivity, invert Y, crouch toggle/hold, aim assist, volumes, brightness, subtitles, text scale, dyslexia font), `PauseView.cs`, `ConfirmDialog.cs`, `BrightnessCalibrationView.cs`. Prefabs in `Prefabs/UI/`. TMP font assets: VT323 (data), IBM Plex Sans (menus), OpenDyslexic (option). Fonts are applied by `UI.UiFonts` (UiKit texts: teal/green = data/VT323, otherwise Plex; HUD views tag their labels); the dyslexia option swaps all to OpenDyslexic live. Aim assist (gamepad only, while aiming) is a gentle pull toward the nearest weak point inside `CameraBalance.aimAssistCone`.

## Rules
- Build canvases with Aura (`create_ui_element`, `set_rect_transform`, `set_ui_layout`, `set_ui_text`) and verify with `capture_ui_canvas`.
- The terminal opens in real time (`Tab`), Inventory context, no pause. It is a world-space canvas on Lukas's left forearm, with a screen-space mirror for readability (setting).
- Contrast ≥ 4.5:1. Text from Localization keys (`UI/`, `DOC/`, `SUB/` tables).
- The menu flow: brightness calibration (first launch) → title (heartbeat only) → main menu in the capsule-row terminal → 3 slots → Survival / Story.

## Acceptance
- No HUD element besides reticle, `E` prompt, subtitles and sync indicator is visible during play (screenshot review).
- Opening the terminal during a hunt: the enemy keeps moving.
- Spanish switch at runtime changes all strings except German ones.
