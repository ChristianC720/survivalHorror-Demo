# Game Design Principles

## Player Vulnerability

The player should not consistently feel stronger than enemies.

Combat must involve meaningful risk.

Avoid introducing mechanics that transform the experience into a power fantasy without explicit approval.

## Inventory Pressure

Inventory capacity is limited to six slots.

New inventory mechanics must preserve meaningful resource decisions.

Do not bypass inventory pressure through hidden or unlimited storage unless explicitly approved.

## Exploration

Exploration should reinforce:

`Risk -> Discovery -> Decision -> Consequence`

Rooms should have a gameplay or narrative purpose.

## Procedural Generation

Procedural generation must preserve authored structure.

Mandatory rooms and progression-critical content must remain reachable.

Randomness must never produce an impossible run.

## Death

Death ends or restarts the current run according to approved game-flow rules.

Respawning is represented narratively through cloning.

## Evaluation Questions

Before approving a mechanic, ask:

1. Does it reinforce tension?
2. Does it create a meaningful decision?
3. Does it interact with another system?
4. Is it understandable to the player?
5. Is it achievable within demo scope?
