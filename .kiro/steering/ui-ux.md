# UI / UX Rules

## Priority

Clarity and feedback take precedence over decoration.

## HUD

Do not expose information the approved design intends the player to infer or discover.

HUD elements should justify their presence through an actual gameplay need.

## Feedback

Interactive states should provide clear visual feedback.

Critical player state changes should be understandable without relying only on color.

## Accessibility

Where practical for the demo:
- support remappable input if scope permits
- avoid color-only information
- preserve readable text contrast
- provide sensible volume controls
- avoid unnecessary flashing

## Menus

Menu navigation must work predictably with keyboard / mouse and approved controller input when supported.
