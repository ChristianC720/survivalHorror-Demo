# Settings Menu — Requirements

Status: Draft

## Objective

Provide a scoped options menu for the demo without introducing unsupported platform or accessibility promises.

## Requirements

## R1 - Audio

WHEN audio exists THE MENU SHALL provide user-adjustable master volume and other approved categories.

## R2 - Display

THE MENU SHALL expose only display options actually supported by the demo build.

## R3 - Input

WHEN input rebinding is approved and implemented THE MENU SHALL expose it through Unity Input System-compatible flow.

## R4 - Persistence

WHEN settings are changed THE SYSTEM SHALL persist approved settings across sessions if persistence is in scope.

## R5 - Safe defaults

WHEN no saved settings exist THE SYSTEM SHALL use valid defaults.

## Acceptance Rule

A requirement is complete only when its observable behavior is implemented and verified.

Unresolved gameplay decisions must remain `TBD` rather than being inferred.
